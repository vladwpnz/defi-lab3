# DeFi Lab 3 — Full-Stack Web3 Application

Laboratory Work No. 3 — Decentralized Finance (DeFi) and Cryptocurrencies.

**Technologies:** Solidity, Hardhat, Ethers.js, Node.js, Express, SQLite, React, MetaMask.

**Implemented features:**
- ERC-20 token swaps using DexPool.
- Swap event tracking and indexing.
- Backend REST API with SQLite database.
- React frontend with MetaMask integration.
- Display of blockchain transaction history.
